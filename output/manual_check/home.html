How this works

Somewhere on this site, eight passwords are hidden. Each one looks exactly like this worked example:

VISUALPING{0000deadbeef0000}

That is: the literal string VISUALPING{, sixteen hexadecimal characters, then }. The example above is not one of the eight — it is only here to show you the format.

  • Every password is reachable from this page — a real browser can click its way to every page on this site. There is nothing to guess: no hidden URLs, no robots.txt tricks. But not every link is an <a> tag in the HTML source.
  • Passwords are not always stored the way you'd first expect — look at everything the server gives you.
  • Keep sending your HTTP Basic Auth credentials on every request.
  • Passwords that appear in HTTP response headers are staging placeholders and are not qualified — ignore them.

The authoritative instructions are in your invite email. If this page and the email ever disagree, the email wins.
